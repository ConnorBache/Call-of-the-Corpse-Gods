# Immutable compiled appearance projection

JSON remains the editable/persisted authority. A Profile owns that JSON plus an immutable Arc sidecar. Defaults compile once from their raw tree; load/parse/from_value/set/reset/reset_group/named compile a fresh sidecar after the final edit. Clone shares the sidecar (the existing JSON Value clone cost remains). No global hash, deep equality of whole profiles, serialization, or cache reconstruction runs merely because a view/paint starts.

The sidecar flattens reachable scalar paths and parses numbers, booleans, strings and RGB values once. It also resolves each terrain entry with the existing no-parent/floor-parent/door-parent rules. Resolution first applies the EXACT original JSON child==default comparison and parent merge. Only then are typed values and default-equality flags produced. Thus uppercase hexadecimal spelling can be numerically identical but remain an explicit customization, exactly as before. Generic Profile::value/material JSON APIs remain for editing and reference code.

Each observed known cell prepares one pre-light Ground record containing its base glyph, colors, fixture status and borrowed typed settings. Neighbor smoothing reads that neighbor's ORIGINAL prepared background, preserving the prior known/current guards; it never uses a previously smoothed or illuminated value. Coordinate noise, lighting, knowledge/fog, feature overlays, pulses, edges and readability math still run on current inputs. No hidden terrain enters the cache and no simulation/RNG state is involved.

## Costs

Let B be JSON/profile owned bytes, D path depth (admitted <=32), P the total bytes of constructed/retained flattened paths, T terrain entries, M material bytes/fields, E flattened entries, N observed grid cells and C known cells. Cold compile costs O(B*D + P*D + 3*T*M) with expected map lookups: raw default-equality compares nested subtrees, and recursive path construction/lookups revisit path prefixes. Color parsing is bounded by string bytes. With the fixed admitted depth bound these factors are bounded, but this is not a strict O(B) claim when depth varies. Extra retained storage is O(flat scalar path/text bytes + raw-equality path keys + 3*T*typed material/glyph bytes). It is not free, compressed, or an RSS guarantee; the diagnostic reports map entry capacities, entry sizes and owned-string capacities, explicitly excluding allocator/hash-control overhead.

Hot scalar lookup is expected O(path hashing/key bytes), worst O(E*key comparison), instead of repeated dot splitting plus nested map traversal and color parsing. Hot material lookup is expected O(material key bytes); no material JSON object clone/merge. Some dynamic call sites still build path strings; this patch does not claim zero allocations throughout observation. Pre-light ground preparation costs O(N + C*material lookup + glyph bytes) and O(N+C glyph bytes) scratch; four-neighbor smoothing reuses those records. Lighting and nonlinear color math retain their existing costs. Whole-view/paint costs are not O(changes) merely because appearance compilation is cached.

The existing profiler gains separate resolved-scalar/resolved-material counters. Legacy raw Profile::value/material/hex counters remain; do not hide new lookup work under a zero raw-clone count. The complete old JSON terrain function and old feature-color function remain test-only oracles. Independent tests compare scalar access against raw JSON, material inheritance/default equality, clone/edit/reset/name/reload validity, all ground flags/biomes, full Cell descriptors and fixed-time pixels. The construction audit measures compiler and validated constructor separately, outside frame timing. Timing results must be produced by the lead after integration; this document makes no measured speed claim.

## Global tone follow-up

After the first compiled-material candidate was measured, ten global numeric controls were stored in one80-byte typed block. `world` borrows it once; exact arithmetic/order and output rounding remain unchanged, but its per-channel formatted `global.*` keys and hash lookups disappear. Raw missing/wrong-type numeric fallback stays0. This removes lookup work, not the necessary per-color nonlinear math. A separate raw-JSON world oracle covers custom control extrema, edit/reload/reset, RGB samples and visibility modes; full descriptor/pixel tests remain required. Existing resolved-scalar counters decrease honestly because these direct field reads no longer invoke scalar lookup.
