# Player animation complexity

Revision-52-only detached presentation, no serialized fields, random draws, wall clocks, or simulation scheduling. Legacy revisions return before capture and emission.

Let A be current-floor actors, K bounded actor metadata, C requested cue cells, and Q a visibility query cost (including existing portal/lighting cache miss costs). Snapshot capture once per accepted command boundary is O(A*(K+Q)) time and O(A*K) extra memory. Finish uses stable actor lookup and bounded ability/condition predicates, O(A*(A+K+Q)); it emits only actor observations admitted both before and after. It does not clone floors, invent hidden identities, or infer movement paths. Actor cloning cost includes owned abilities, conditions and equipment metadata, not only position.

Exact footprint construction is bounded by 16 duel perimeter cells, 9 Cogworks pit cells, 5 wall cells, or one Clay Soldier cell. Events independently filter requested cells in O(C*Q) time and O(C) detached memory, under the central batch cap. Pursuit activation uses the existing actual route computation: its O(V*(A*P+Cterrain)+field(V,L)) cost and O(V+L) scratch are documented in revision50_pursuit.rs and movement.rs. Animation does not substitute a straight line for that route.

Direct damage/reaction/rescue hooks add bounded cue work and existing stable actor lookup O(A), plus Q. Multi-step pushes emit once per actual committed step, with the existing world-cell limit; no new movement planning or random choice is added. No timing measurements are claimed. Run the native unit/integration suites and profile busy observed actor floors, portal-heavy route activation, and inactive legacy saves to measure cache-hit/miss costs.

Symbolic transfer fidelity adds two admitted endpoint checks per link, O(Q), with no pathfinding or intervening-cell enumeration. Remember clones only its actual newly acquired trait-ID list for presentation, O(K + total ID bytes) scratch/time, and emits one bounded event per acquired trait plus one apparent glyph outline. This clone occurs only at revision 52; legacy simulation data and RNG remain unchanged.

Final corrections: snapshot capture/finish additionally derives Hardened Blood protection for observed owners with that passive. This calls existing effective-stat and health helpers, so add O(A*S) time where S is the full existing stat derivation cost (including inventory/effect and owner lookup costs), not constant arithmetic. Actors without the passive return immediately. Radius outline activation builds a V-cell directly observed/range mask and checks four neighbors: O(V*(Q+R)) time and O(V) temporary memory, where R is the existing portal-aware half-here range query and Q the visibility query including cache misses. No outline work runs on upkeep. This replaces interior-cell marks; no hidden cells or unknown boundaries are emitted.
