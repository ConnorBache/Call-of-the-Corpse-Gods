# Owned overlay geometry: shared custom-layout integration

Pack, Inspect and hover now consume shared profile-derived bounds through `modal_ui`. Pack caches measured text metrics during configure; input and paint share row/button/close rectangles. Inspector bounds/disclosure/scroll and hover width use the same profile-derived layout. Default geometry and authored-profile regressions pass. This document retains the source formulas and identifies broader remaining typography/renderer gates.

Frozen source references: `ui-interface-appearance.ts` applies only nondefault overrides; `ui-overlays.ts` owns Pack and tooltip placement; `style.css` owns shell, columns and inspection CSS. The inert legacy `leftSidebarWidth` must remain inert.

Implemented detached integration contract (concrete names: `modal_ui::Frame`, `PackLayout`, `PackView::configure`, `inspection_ui::bounds` and `close_hit_profile`): the presentation owner computes one `FrameGeometry { viewport, map_column, projected_dungeon, chronicle_height, sidebar_width, command_height }` from current Profile/window. Each owned module gets geometry before input or painting. `PackView::configure(frame, typography/layout)` should retain its resolved bounds/list/detail/close/cancel rectangles and row height; click/key/scroll/paint all use those same values. `inspection_ui::layout(frame,profile)` should return panel/hover dimensions; click/disclosure/close/scroll and paint take that same layout. Avoid paint-only transforms or independent hitbox math. The profile is presentation state, never Run state.

Source formulas:

- Sidebar: clamp(min(290,rightSidebarWidth), sidebarWidthPercent*viewportWidth/100, rightSidebarWidth). Shell column-gap is mapSpacing. Chronicle grid track is chronicleHeight+12. Default Chronicle height follows its fontSize*lineHeight*4.5 when typography changes and chronicleHeight remains default. Command height is buttonHeight+4 when authored. Inspector strip stays32px.
- Pack placement uses the projected dungeon rect: margin=min(12,width/4,height/4); width=min(900,mapWidth-2*margin); height=min(760,mapHeight-2*margin); right/bottom anchored with that margin. Source drawer content has40px header,8/12/12 section padding,28px counter row,42px target/action row, then a bounded scrolling row region. Columns are1.25fr and1fr with12px gap. The twenty-slot capacity is presentation-only; authored inventoryRowHeight changes rows inside this fixed window, not the window's dimensions.
- Deliberate floating inspector: left24; top=chronicleHeight+30; width=min(520,viewportWidth-sidebarWidth-48); height=min(580,viewportHeight-chronicleHeight-120). Native overlays preserve map-column containment. Source floating-panel placement/drag state is independently owned; Pack close must not overwrite Inspector placement.
- Hover: source tooltipMaxWidth capped by viewport minus16; maximum height=min(620,viewportHeight-16);8px viewport margin and5px tile gap. Prefer below if it fits, otherwise above; center horizontally on the source tile, then clamp. Native current geometry intentionally uses the map column as the horizontal viewport to preserve the rail. The existing helper takes a measured height; it needs authored width rather than a literal520, and wrapping must use the resolved content width.

Additional authored settings requiring the same pass: tooltip/inventory font size, line height, font weight/family, border width, panel/selected/hover colors, button height and horizontal padding. Current global Painter profile handles some text/color overrides elsewhere; owned modules must not claim arbitrary custom-layout parity until their resolved hit regions and scrolling are tested across min/max profiles.

The presentation module now exports `render::hud_left(&Profile)` and `render::chronicle_height(&Profile)`. Reuse these authoritative values in the next owned-layout integration rather than duplicating shell formulas. Their default results are985 and108 respectively.

## Verification and remaining gates

Added six frozen-source Pack placement and36 authored-width hover fixtures, four pure geometry/wrapping tests, and two custom-profile interactive paint/input regressions. Existing64 Pack behavior fixtures,80 hover placement fixtures and inspection observation tests remain unchanged. Authored fixed inventory rows clip oversized fonts instead of growing tracks. Pack/Inspector/hover currently use logical1280x800 dimensions; physical-window scaling remains main-loop ownership. Source CSS descendant inheritance, arbitrary platform fonts and exact font weights/raster outlines remain distinct visual-parity gates. Other modal consumers are not certified by these tests.
