## Complexity

Classification scans T authored traits at most a constant number of times: O(T), O(1) scratch per event. Local hooks are O(1) plus central visibility/plane admission. Footprint hooks reuse resolved cells: O(C * V) time and O(C) detached output for C actual cells and visibility-query cost V, bounded by floor dimensions and the event cap. No new gameplay search or RNG.
