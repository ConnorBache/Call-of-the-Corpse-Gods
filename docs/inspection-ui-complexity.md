# Native inspection checkpoint

`inspection_ui.rs` ports the frozen v48 `ui-inspection.ts`, `ui-terrain-inspection.ts`, creature descriptions, gas exposure copy, and pure combat forecast formulas. `observe_tile` is the only Run-consuming adapter. Painting receives a detached Report and never queries the simulation. Observed actors are admitted only by `vision::visible_actor`; remembered terrain/items use saved snapshots. A banshee sound marker replaces, rather than enriches, other information. Missing terrain memory remains unknown.

Source fixtures: `tools/export-inspection-ui-fixtures.mjs` exports 58 terrain reports, 187 creature reports (including dual wield, primary/offhand-only/bow, preparations, reactions and conditional offhand outcomes), and 64 gas exposures. Seven native tests additionally prove hidden-state mutation cannot change remembered reports, snapshot-item deduplication, sound-only redaction, bounds, scrolling, and repeat-open rendering. Inspection queries preserve serialized Run and RNG.

Cost: tile observation currently inherits vision's full-floor observation cost and O(V) detached allocation; creature status/copy queries are O(abilities + actors + inventory). Forecasts copy only player, inventory and Arc floor/actor handles into an explicitly incomplete read-only combat context, never history/log/replay/archive payloads. Branch actor mutation uses COW on current actors. Hardened Blood/Surrender conditional range analysis uses a fixed 48-iteration search. Painting is linear in wrapped report text and bounded to the source 520x572 floating drawer at (24,138), never covering the right rail.

Dynamic creature ability prose in `creature_abilities_ui.rs` now passes all 1024 frozen-source cases and supplies compact/full mechanics fields. It covers intrinsic and legacy traits, player-controlled effects, copied durations, shared resources, activation/upkeep costs, timed states, silence and suppression. No JavaScript executes at runtime. Source native simulation gates remain authoritative independently of inspection predictions. Pointer-transparent hover uses a detached resource-meter projection, including Half Here, Sphinx and Boundless Hunger, source compact report sections and source tile-anchored below/above geometry; full mechanics remains in the deliberate inspector.
