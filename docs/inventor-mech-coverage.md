# Hemogoblin Inventor and Mech

`monster_inventor.rs` implements physical-shell identity (retained when traits are erased), empty-shell neutrality, same-tick mounted hold, inventor flee/path/mount decisions, ordered actor removal and nested pilot storage, and destroyed-shell removal followed by unavoidable pilot death. Pilot landing uses source direction order, diagonal geometry and corpse-space rules; it prefers no living occupant but may share living space when no unobstructed adjacent cell exists. Generic corpse placement owns final overflow. Carried-item placement remains authoritative and preserves item IDs/order.

The fire-breath helper traces the exact six-cell-radius cone in row-major order. Line-of-sight and projectile landing checks precede each native ignition; gas/fire reactions resolve through the shared environment implementation. All ignitions precede actor-order direct fire packets and independent burning RNG draws. Cooldown/recovery, visibility-filtered logs and presentation events follow the source ordering.

Raw frozen-source tests in `monster_inventor::tests` compare26 complete states, return values and event lists: ordinary/haste mount, flee/no target, erased shell, mounted tick, ally mount, cone obstruction/cooldown/range/lethality/explosive gas, and empty/occupied/blocked/carried/heartless pilot death. Six mixed dispatch/history/event traces in `tests/inventor_traces.rs` pass approach/mount/spray, inert shell, melee/fire shell destruction with pilot corpse, inventor carried-loot death and haste mounting. Every canonical state field, event, reconstructed history opening and pending-haste state is compared. Offscreen family tests are owned by the environment suite. No generic fallback represents this family. Ambiguous duplicate pilot IDs are rejected before helper mutation because detached legacy object identity is not represented by the native stable-ID execution boundary; a rejection regression verifies unchanged state.

## Complexity

Let A be current-floor actors, V floor cells, I carried items, E actor condition/ability size, and R maximum projectile/visibility ray length.

- Inventor decision scans O(A) for the linked shell. Mount clones one pilot O(E), removes one actor O(A), and mutates the shell; shared actor storage can detach O(A*E). Retreat evaluates at most8 destinations including actor occupancy/hazards. Approach adds the shared actor-specific pathfield cost, including V-cell masks and shortest-path work; no unbounded randomized movement attempts.
- Pilot landing checks8 candidates, O(A) corpse/occupancy checks per candidate plus traversal/habitat queries. Destruction includes carried authoritative placement and ordinary death/heart/corpse hooks; those additive costs include possible missing-floor generation. The nested pilot is transferred, not cloned into a second living actor.
- Fire cone scans169 candidate coordinates; each accepted coordinate performs O(R) sight/projectile work plus native ignition and any reaction closure. Victim selection O(A), then direct damage/burning per victim; shared actor mutation and death hooks add their own costs. Scratch is O(169+A). Six-cell cone bounds do not bound gas reaction chains or arbitrary world-generation costs.
- Differential fixtures/export run only during development. Runtime invokes no JavaScript. No performance improvement or whole-game parity is implied by these tests.
