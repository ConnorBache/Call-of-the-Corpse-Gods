# Actors and command complexity

Variables: F floors; V active-floor cells (supported grids <=3600 in pathfinder); A active actors; I inventory entries; R maximum ray length; S light/dark sources; P shared viewpoints; L archive dictionary messages; G ground items. All bounds below are static analysis, not timings.

- Raw command transaction: O(F+A_groups+G_groups+I+small-run-metadata) snapshot setup and references, excluding first writes. Replay/history/archive/haste strings are moved into the candidate, not cloned. Failed execution truncates append-only replay/archive cursors and restores ownership. Floors and per-floor actor/ground vectors use Arc COW, with O(V) or O(A)/O(G) detachment on first mutation. No total-world tile clone per action. Small inventory, player conditions, recent logs and knowledge metadata still clone; this is not a complete minimal journal.
- Archive append currently searches interned messages O(L * M) per log event for maximum compared message length M; bounded recent log shift O(80). A persistent dictionary cache remains unimplemented. This is a known cost, not an amortized-O(1) claim.
- Path field: BFS O(V+E), Dijkstra O((V+E)log V), E<=8V; O(V+E) extra heap/queue/maps. Scalar cost uses hazard priority then step count then diagonal count. Engine reuses phase-local fields by target and traversal profile; worst case O(A V log V) when each actor needs a distinct field, while shared keys reuse the field. Newly hazardous next steps invalidate routing as source. Pure field expansion still allocates <=8-element adjacency vectors per vertex; no speed claim.
- Vision ray O(R), O(1) scratch. Each tile-light query includes bounded 15x15 fire sampling plus static/actor source scans O((S+A)R + 225R). Whole terrain mask currently O(V((S+A+P)R+A)) time, O(V+P) output/scratch. No persistent cross-tick cache. Direct rays do not allocate whole-floor opaque vectors.
- AI phase scans actors and builds stable IDs O(A), haste sort O(A log A), stable partition O(A). Each current ID lookup is O(A); broad worst case O(A² + A*vision/path cost). Source cache optimizations not all integrated.
- Ground/corpse placement O(V+G/A) time with bounded scratch occupancy, ordinary local paths; shared item placement can traverse <=40 floors and generate missing floors through the startup callback. Engine death now uses shared corpse placement across up to 40 floors. Blood splatter examines nine cells and uses <=5 RNG selections, O(1).
- Resource observations O(A*actor_visibility + I*A) worst case because effective stats scan equipment. History storage O(A). Resource loss for one actor queries visibility and stats, not O(1) in general.
- Observation commits O(V*visibility + G²) current simple remembered-item reconciliation; bounded I is not assumed for ground count.

Frequency: paid normal commands run actor upkeep/AI/environment once (Slowed runs a second normal turn and intervening haste phase); haste movement does no upkeep/status tick/regeneration; free commands still perform observation and pickup per source. All unsupported branches must preserve caller state and RNG. Differential traces check semantics independently of these estimates.

## Ordered visual output and pending haste snapshots (2026-10-19)
Presentation events are command-scoped and outside Run. Ordinary storage is bounded at128 events; removing oldest event is O(128). Explosion dedup uses insertion-ordered IndexMap keyed by floor/cell, bounded by observed explosion cells. Visibility queries at emission retain their existing ray/light costs; event emission consumes no RNG. Errors discard the batch. No cache keyed by mutable Run addresses is retained.

Successful haste-only movement returns a typed Arc snapshot captured from the exact phase-opening state (after command/replay increment), including archive cursor. It excludes replay/history/archive; the large Future anchor string can still be cloned once on pending-snapshot capture and remains a documented optimization gap. Ordinary actions do not add a second typed phase snapshot capture. The transactional phase-before Run clone remains, sharing floor/actor/ground Arc blocks.

Adaptive Armor canonical alias dictionary is parsed once lazily and queried O(log K); heart-count arithmetic is O(1). Species no-bleed metadata shares the frozen enemy-traits catalog; current definition lookup scans the bounded authored definition vector O(K), including event identities. Lifecycle world clocks scan actors, with Banshee line-of-sight and nested victim effects retaining their own costs. Carried-item death placement adds one shared placement search per carried item.

Vampire/Wendigo/Inventor specialized turns scan candidate actors O(A); pursuit uses the same path fields. Nova can add an explosion per primary or recursive attack, with environment costs separately documented. Rescue scans acquisition-ordered abilities O(B), no RNG; Overflowing accrual loops once per 50 damage packet threshold, preserving source arithmetic. Maintained-link cleanup scans actors and five links at actual death.

Post-death references use stable IDs with current-floor lookup first and cross-floor fallback O(sum actors) only where source retained a moved corpse. Source snapshots are fallbacks for removed attack endpoints, never reinserted into occupancy. Typed source snapshots do not copy floors or actor collections.

21:15 additions: capability preflight constructs each actor's inferred trait union in O(B + K) per actor (B abilities, K immutable definitions) using immutable authored metadata, preventing unmarked imported actors bypassing mechanic gates. Erase chooses/removes one ordered ability in O(B), with one authored RNG draw only after successful payment and a nonempty victim pool. Remember expiry scans condition keys and filters affected ability vectors; no whole-world clone is introduced. Redirected projectiles carry a shared stack Cell for callback-hit aggregation through recursive strikes; this adds no RNG or authoritative state. Failed paid command rollback preserves newly introduced optional damage counters, matching source Object.assign omission semantics.

Ally order control does one O(A) perfect/living actor lookup and then the same free-command observation work. Mini-Me offhand adds at most one secondary attack for each primary and cannot recursively offhand. Sphinx provocation performs a bounded condition update without RNG; first-provoker observation scans at most two player body origins plus ordinary LOS. Immutable capability validation checks all inferred source traits but runtime raw-list queries remain raw where the frozen source uses abilities.includes.

21:40 bounded composition additions: habitat-stranded command preflight performs a habitat query and, when stranded, the existing haste/world phase rather than opening ordinary attack damage counters. It applies even to otherwise free commands; worst-case cost is therefore the same phase cost as a paid action. Direct lever interaction adds an O(1) adjacency check before the separately documented reward/placement helper. Offscreen Mini-Me admission performs the bounded starter-ID whitelist lookup per ability; terminal status callbacks relookup the current actor ID and skip a removed body rather than retaining a mutable actor across callbacks. These are source-order/correctness changes, not measured speed improvements.
