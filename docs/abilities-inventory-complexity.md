# Native abilities, inventory, equipment and progression

This ledger distinguishes parsed catalog entries from executed mechanics. All 72 authored definitions are frozen in `crates/corpse-core/catalog/abilities-v48.json`; catalog presence never permits an unimplemented activation. Runtime has no JavaScript VM or dependency. Export scripts only create development-time differential fixtures from frozen v48.

## Cost boundaries

- Equipment slot changes scan I carried items: O(I) time, O(1) extra mutable state excluding the command candidate snapshot. Two-handed weapons occupy both hands, represented once in hand 1. Resource settling scans equipment bonuses O(I); stat count is fixed at eight. Admitted granted abilities reconcile through the authored ordered ownership helper; unknown grants reject. All five craft families are described below.
- Stack pickup scans G ground entries, doing O(I) inventory scans per matching entry, plus fixed-size stat-key serialization for legacy Jackal hearts. Worst case O(G I + G L), O(G + I + L) extra storage, L serialized item metadata. Arrow bundles count as one slot, legacy heart stacks count each quantity. Ordinary capacity is 20; Guile enhancements add five slots each; unsupported crafted capacity cannot silently use 20.
- Drop destination uses O(V + G) time and O(G) occupancy memory; squared Euclidean distance then row-major order. V is active floor cells. Cross-floor falls delegate to the authoritative item-placement and floor-creation adapters. Splitting a stack preserves its old identity and assigns exactly one new nextId.
- Consumable changes are O(I + A²) worst case when a heart causes blessing offers. A=72 authored abilities. Known potion identification scans I bottles. Fixed actor stats and timers are O(1). Normal command scheduling, visibility and environment are additional caller costs, not hidden in these estimates.
- Offer weighting scans authored descriptions and acquired ability tags, O(A² D) worst case for A bounded catalog entries and D maximum description length, with O(A D) temporary data. Catalog is parsed once using OnceLock: O(total JSON bytes) time/storage on first use. Each later use shares immutable definitions. No RNG is consumed for weighting; each actual offer draw consumes exactly one simulation sample.
- Sparkle activation performs visibility validation (see vision ledger), O(S) search in permanent-fire/source lists of lengths bounded by floor size V, then environment ignition. Environmental propagation/contact and first COW floor detachment are additional O(V + actors + provenance) costs documented by that subsystem.

## Verified scope

Nine boundary differential cases cover slot transitions, full-capacity arrow merging, clearing departed auto-pickup blocks and Dilute Potion healing reuse. A four-command full-state trace covers full and half healing, stacked heart ID splitting, permanent stat growth, blessing bookkeeping and deterministic level-up offers. A ten-command inventory trace covers equipment, both Unyielding toggle directions, passive invocation, dropping and recovering arrows. Temporal history is deliberately excluded from these trace comparisons; all other fields are compared.

Weighted-choice tests compare every authored ability's weight under three ownership sets (216 weights), plus 12 exact selections. These tests verify offering, not execution of the offered abilities.

No platform/UI performance measurements are claimed. Test with `tools/cargo.sh test -p corpse-core inventory` and `tools/cargo.sh test -p corpse-core progression`.

## Subsequent native slices

- Guile/Artifice/Zeal crafting and Divine Craftsman scan I items, A abilities and E selected-item enhancements. O(I+A+E) time, O(I+E) item copies for transactional command state; stats are bounded at eight. Capacity-change previews clone only inventory (O(I+E) space), never temporal history. Reclassifying already-sensed magic does a cold equipment-catalog parse once; subsequent legacy-name matching is O(C N), C catalog size and N maximum name length. No classification reveals unsensed properties. Fury and Dream now have source command traces, including per-action funding and shared-owner flight/resource loss.
- Loot generation accepts the independent GenerationRng and caller nextId. For L<=20 loot slots, catalog C and abilities A=72, worst case O(L(C+A)) plus string copying. Arrays and output require O(L+C+A) additional space. Draw order, duplicate grant exclusion, signed modifiers, armor multipliers, godbeast reward scaling and the starting-Bow exclusion follow v48. Generated grants execute when their ability hooks are admitted; unknown mechanics still reject before mutation. Stable grant reconciliation/counter retention uses the source equipment_abilities adapter.
- Heart creation copies one frozen authored species template, O(H) item size, or evaluates bounded Pale/fish/Zillennia reward formulas. Lookup uses an insertion-ordered hash map, expected O(1), worst-case O(C) hash lookup. Unknown species fail explicitly. First catalog parse is O(total catalog bytes) time and storage.
- Water float selection consumes exactly one fair coin per eligible swimming exposure, even for empty packs; a successful nonempty selection consumes one further weighted physical-unit sample. O(I+V+G) time, O(G) occupancy space. Twelve source differential cases verify serialized RNG, quantities, IDs, ground placement and logs.
- Expanded potion/ability traces compare every non-temporal field after each command using lossless expected-state patches. Eleven potion effects ×23 commands verify full/diluted reuse and expiration; Make Kneel and Sudden Sleep verify free/paid phase semantics. Separate temporal wrapper tests own history/rewind behavior.

Latest verified additions: full crafting command traces, all authored heart reward fixtures, 126 loot/reward RNG cases, and 278 expanded consumable/status/ward/reveal commands pass. Revert/Future end-to-end parity covers 64 commands and their presentation events, all gameplay fields, reconstructed history opening/pending snapshots, and save/resume. Temporal acquisition, failure/paralysis and offer blocking are included. Serialized history representation is normalized only for semantic snapshot comparison; future anchors are decoded before comparison.

Temporal command wrappers emit exact success logs and presentation pulses, then synchronize ownership and doors without ordinary pickup/visibility history side effects. Successful haste movement returns a COW phase-opening snapshot plus archive cursor to the temporal wrapper; no JSON snapshot capture is added to the command hot path. Temporal signature detection serializes player/inventory/selected target only on temporal commands; future serialization and legacy history export remain explicit boundary costs documented in the temporal ledger.

## Bow and ordinary thrown items

Physical projectile rays use source integer Bresenham cells, excluding the source and stopping before wall/tree/closed-door terrain or on the first living creature. Trace cost is O(R A), R ray length, A floor actors; O(1) auxiliary memory. Grates, wards and corpses do not block rays. Bow preflight scans I inventory entries and rejects before resource observation, pickup, haste/history capture or RNG. Firing detaches one arrow, applies source half miss-chance scaling, destroys arrows on successful hits even when mitigation yields zero damage, and uses exact ground-placement semantics otherwise. Ordinary thrown one-handed weapon damage follows authored base/enchantment/offense rules; other ordinary items use player offense. Potion throws explicitly reject until their environmental effects are ported.

Thirteen source traces cover 67 commands and presentation event arrays: six combat seeds, empty/wall rays, ammo exhaustion, rejection boundaries, and thrown starter sword/bow/arrows. Ground placement delegates to the authoritative item-placement subsystem, O(V+G) per visited floor plus floor-generation cost when required. Its ensure_floors callback supports cross-floor drops and thrown items; source removal remains caller-owned. NPC callers share trace_from for intended-victim path validation.

Starter modes add O(A) ordered upkeep/funding scans, O(1) targeted condition changes after O(N) ID lookup, and existing visibility costs. 127 command/event comparisons verify funding, expiry, combined upkeep and occluded sensing; 72 combat starter steps verify reactions/luck/flight/kill hooks. Mind-control changes remain O(N) lookup plus scheduler cost; 93 full command/event comparisons verify thresholds, self targets, sleeping targets and temporary ally expiry.

Detect Magic memory refresh is O((I+G+D+R)C N + V) worst case for inventory I, ground G, detected D, remembered R, equipment catalog C, name length N and visibility cells V. It uses O(G+D+R+V) temporary snapshots/sets; inventory classification currently clones each item before deriving its physical magic nature. Four direct memory fixtures and the 278-command expanded consumable/event suite verify sensitive and expired state, potion nature without identification, and legacy gear classification. Temporal commands rebase retained opening snapshots only at temporal boundaries, O(H S) with H<=5, preserving sparse inverse semantics across upkeep mode removal.

## Linked bodies and additional divine commands

Half Here activation validates one visible cell and scans A actors for occupancy, then delegates projection/lifecycle to half_here. O(A + V) time including visibility and O(actor-size) allocation on creation; deactivation scans/removes the endpoint. Shared health/resource hooks remain in the combat scheduler; endpoint-local conditions are not merged into the owner. Three activation command scenes (23 steps) compare complete state and presentation events. Population and environment suites separately cover lifecycle, falling, shared gas-pool deduplication and bodily explosion exposure.

Blood Weapon activation is O(K + A), K owned abilities and A actors for owner resolution/synchronization. It pays the source rounded maximum-health fraction through exact-scale damage, primes only a living player in a playing run, and repeated activation while primed does not pay. Twelve source scenes (56 steps) cover lethal payment, repeat activation, attacks, rounding and combined Fight Long/Beat to Death/Hardened Blood behavior. These caught and fixed the source maintainSkills synchronization placement before enemy turns. Ascend delegates vertical travel and its existing floor/actor costs; seven source scenes (19 steps) cover success, failure, haste and passive water/fire flight contacts.

Potion display uses a bounded authored appearance table and independent seed hashing/LCG, never simulation RNG. Hidden-potion unsupported-use errors intentionally omit the private effect name; previewing support by hidden effect would itself reveal information and is avoided by the UI.

Legacy inverse imports preserve missing/null distinctions: a patch with neither value nor remove encodes JS undefined. Canonical object restoration removes that key; an array slot becomes null, while explicit null remains null. A dedicated unit regression plus seven linked-body command/history traces prove this boundary; no source-parity exception is required.

Equipment changes capture maximum energy, Boundless ownership and both body flight flags before mutation. Reconciliation precedes resource loss; crushing precedes rescuable death, then linked-body and player falls settle in source order. Nine grant command scenes 48 steps and ten Dream Craft scenes 30 steps pass. Fury scans equipped enhancements once per attack action, O(I+E), consuming exactly 10 energy per funded active craft and disabling unfunded crafts; nine scenes 48 steps include Unyielding Assault.

Tinker scans 72 abilities plus inventory and all ground grants, builds outside-god pools without changing their probabilities, and uses exactly two serialized RNG draws. A local scalar RNG probe rejects an unsupported selected mechanic before any mutation; successful commands commit identical draws,100 energy, name/ledger changes and equipment settling. Runtime requires no JavaScript.

## Final divine activation expansion

Unspeak scans one target's initialized traits and immutable divine descriptions, O(A + description bytes), once at activation and once per normal maintenance turn; upkeep reads its cached cost in O(1). Remember preflights one detached target, then copies only supported passive mechanics and writes five-turn counters; unsupported copies leave the entire transaction unchanged. Fast/flight expiry has full command coverage. All 44 authored enemy passives are now admitted, with the all-passive cohort documented below. Silent Strike, Sleep Walk, Step Through Shadows, Erase, Uncast and Wheel use native combat/scheduler hooks and focused command oracles. The 72-row coverage ledger distinguishes executable paths from untested combinations. Silence is checked before paid activation, including temporal commands, with zero-cost Future anchoring/return preserved.

## Complete potion effects and impacts

The shared `potions` module applies all authored effects plus legacy Veridian Sap. Impact resolution is O(N) actor lookup, O(I) identification/consumption and bounded stat work, plus the existing environmental/visibility/travel costs of gases, ignition, detection and descent. Health/energy and Defense buffs resolve to a Half Here owner; bodily statuses/offense remain endpoint-local. Drinking preserves Dilute Potion reuse and Tools of the Trade timing. Throws always consume the bottle, use the integer projectile landing, and grant Sap blessings only on the physical player body. Source suites cover 200 new drink commands and 414 thrown commands across 138 scenes, including linked-body and descent combinations. Exhausted offer pools have nine deterministic source command scenes across all three authored modes. Tree Tap use has six source scenes / 24 commands covering nearby, distant and harvested Veridian with and without Tools of the Trade.

## Copied passive and starter cohorts

Remember metadata classification is O(P), where P is a target's ordered ability list; immutable enemy metadata lookup is O(1) average. It admits the frozen catalog's 44 passive entries, while source-specific AI-only mechanics remain scoped to NPC scheduler sites. The all-passive fixture contains 139 scenes / 1428 commands, including owner/endpoint copy, combat and expiry; the complete final regression passes after copied habitat and shared-body gas provenance fixes.

Mini-Me's copied-power preflight is O(P), using 15 fixed starter IDs. Source command tests cover all 416 legal three-god starter combinations (2080 commands), individual starter combat/hazards (39 scenes / 813 commands), and clean/dirty offscreen plus lethal Burning/venom cohorts (32 scenes / 768 commands). Environment ticks retain at most one Half Here endpoint snapshot, O(P + C) body state for abilities P and conditions C, so a removed endpoint still receives source gas-provenance cohort updates after shared-owner death. Provenance is authoritative ownership state; it is compared exactly, not normalized away.
