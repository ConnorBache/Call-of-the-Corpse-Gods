# Knowledge-limited projectile preview and Bow hover

`targeting_ui.rs` ports frozen `ui-targeting.ts` and `projectile-ray.ts`. It returns a detached integer Bresenham path and Target/Unknown/Terrain/Creature/Invalid stop reason. The physical player is the origin, including shared-sight/clone views. Current observation is checked before every live tile/door query. Remembered terrain is insufficient for a projectile preview. Walls, trees and closed doors stop before the cell; grates, corpses and wards do not. The first observed living interceptor is included and ends the path unless it is the requested endpoint. Hidden occupants are never collision inputs.

`inspection_ui::observe_bow_tile` appends the source Bow-shot row only to an already-observed creature's hover report. Inventory/equipment/ammo blockers precede known obstruction and unknown-path prose. The numeric forecast uses source hunting posture, range loss, Bow's 0.5 ordinary miss multiplier, reactions, explicit luck/paralysis/protection ordering, weapon/enchantment/effective stats, Fury funding, mitigation and Nightmare absorption. Source raw hitChance is preserved; no omniscient projectilePathClear result is exposed or consulted. Main owns pending-target state and paints only the detached source-red ray.

After observation classification, ray construction is O(ray length + observed actors), with O(path length + actor occupancy) memory. The public Run adapter additionally pays the existing terrain/actor visibility costs. Bow reports reuse pure strike formulas and a small read-only combat context; no history/replay/log clone, simulation write or RNG draw occurs. Desktop should cache the projections until pointer tile or observed simulation state changes.

`tools/export-targeting-ui-fixtures.mjs` exports 275 source ray cases and141 Bow reports. Native tests compare every result/string, assert Run identity after queries, and mutate hidden terrain/interceptors to prove they cannot affect preview. Cases include unknown/remembered cells, closed/open doors, diagonal rays, visible/hidden living actors, corpses/zeroHP, target interception, invalid endpoints, both Bow types, hunting/sleeping posture, near/far distances, explicit attack guarantees, Not There, Turning the Wheel, Nightmare, Surrender, Fury, Shine, Drown and equipment/ammo blockers.
