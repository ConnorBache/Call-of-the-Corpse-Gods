# Native dynamic creature ability descriptions

`creature_abilities_ui.rs::describe` returns detached compact/full mechanics strings for an actor already admitted by observation. It ports frozen `creature-ability-description.ts` and source authored metadata exported into `assets/creature-abilities-v48.json`. Actor traits, legacy-name fallbacks, erased traits, clones, independent AI, costs/upkeep, copied durations, statuses, recovery, charging/cooldowns, suppression, resource sharing and controlled divine abilities are projected without mutation or simulation RNG.

`tools/export-creature-abilities-ui-fixtures.mjs` produces 1024 source oracle cases: catalog/legacy/erased bestiary entries; every enemy ability with empty/funded resources, timers and clone ownership; divine abilities across player/creature, active/inactive, funded/unfunded states; Pale identity and lifecycle special cases. All 1024 compact/full strings compare exactly. Native query leaves Run unchanged. Compact/full results are attached once to a detached inspection report and cached by the desktop observation owner.

With K intrinsic/owned ability entries, D immutable definitions, I inventory records and A current actors, metadata/classification scans are bounded by O(K*D); cost/state queries may add actor/inventory scans and output-string size. Deduplication uses source insertion order, with HashSet membership only, so hashing cannot reorder visible prose. Immutable authored data is parsed once with OnceLock. Output memory is O(text + K). No floor/history/replay clone or JavaScript execution is involved. Full mechanics disclosure is user-opened in the deliberate inspection panel and never part of pointer-transparent hover hit-testing.
