# Native mouse travel: source behavior and costs

`travel_ui.rs` ports frozen v48 `player-pathing.ts`, `ui-travel.ts`, and `main.ts::clickMove`. `path_to` consumes a Run only at the input/observation boundary. The returned Steps contain entered coordinates and predicted arrival coordinates; renderers never receive a Run through this API. `start` preserves deliberate adjacent input, including attack/manual movement independent of route preferences. Replans always use `direct_adjacent=false`.

The graph uses the exact N,E,S,W,NE,SE,SW,NW neighbor order and four phase states for haste/I Came For You. Stable priority/order tie-breaking matches the source. Costs minimize fire/gas exposure first, then wet commands, commands and diagonals. Typed-zero gas remains hazardous; embers alone are safe. Flight/Drown do not admit deep-water route entries. Ichor supersedes underlying water. Known stairs/final pits cannot be intermediate waypoints; known chasm/pit destinations retain deliberate endpoint handling. Current and quarry inputs use remembered terrain and observable actors. Missing legacy terrain memory is conservatively unroutable: source `planPlayerTravel` has a live-tile fallback for absent rememberedTiles, whereas source map artwork already rejects incomplete remembered neighbors. Normal complete-memory routes retain exact source parity; hidden state never supplies a substitute native tile or habitat.

The controller snapshots only observable actor ID/state/death and own HP. It stops on terminal/level-choice state, non-adjacent route steps, live movement obstruction, forced displacement, depth change, hazard confirmation, newly observed/woken/stalking/hunting enemies, harm or paralysis. Observed blocking creatures receive one ordinary Move/attack then stop. `after_step` replans to the original goal after each successful command. Main owns the 45ms timer, cancellations, all modal/targeting priority, and temporal dispatch. A discarded Travel has no simulation effects. No private Run/history clone or RNG consumption occurs.

For V cells, S=4 phase states, A actors and G grates, observation allocates O(V+A+G) detached data and adds the existing vision queries' costs. A single hazard context indexes roots/vents/fire/light fixtures, so no per-edge world scan is introduced. Unweighted search is O(V*S*8), weighted search O(V*S*8*log(V*S)), with O(V*S) arrays plus bounded-degree heap entries. Actor visibility and current occupancy are indexed once per plan. Stable costs use exact integer arithmetic within the source legal floor sizes. Threat comparison uses O(A) expected time/memory. Controller path removal is O(path length), matching source shift; each successful automatic move recomputes one knowledge-filtered route. UI caching/invalidation remains the desktop owner's responsibility.

`tools/export-travel-ui-fixtures.mjs` exports 256 player-route cases, 96 displaced phase graphs and 56 threat transitions. Seven tests compare all routes/ties/reasons and cover cycles, hidden-live mutation isolation, missing memory, deep-water exclusion, controller progress/replanning and harm/displacement/hazard/obstruction stops. Development fixtures use the frozen JS reference; the shipped executable does not.
