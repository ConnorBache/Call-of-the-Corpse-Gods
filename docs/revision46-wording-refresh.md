# Revision 46 description refresh

Five designer-supplied descriptions replace only displayed text: Sparkle, Star Power, Adaptive Armor, Artifice Craft, and All-Seeing Eyes. Adaptive Armor retains its live current-adaptations suffix. Make Kneel, Divine Craftsman, Turning the Wheel and Sever Fate are unchanged.

This does not change mechanics, costs, Sparkle's combustible-square restriction, All-Seeing Eyes' time-consuming-action lifetime, revision selection, catalog prose or offer classification. Existing revision 46 saves remain compatible; older revisions retain prior wording.

The fixed display match is O(1) time and memory per call and returns borrowed text. The existing Adaptive Armor suffix still scans A adaptation entries and allocates O(T) output text in O(A + T), where T is emitted text length. No new world, inventory, save or rendering pass is added. Tests cover exact description routes, live empty/nonempty suffixes, unchanged approved strings, catalog/Run bytes and selection order.
