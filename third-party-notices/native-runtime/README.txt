Native runtime dependency notices

These files preserve notices from the exact dependencies used for the Windows x64 cross-build. They do not grant a license to the game itself. No compiler or SDK is included in the player package.

Rust-1.99.1-COPYRIGHT-library.html: copied unchanged from the official installed Rust 1.99.1 standard-library copyright notice (2026-10-15 release).
MinGW-w64-12.0.0-COPYRIGHT.txt: copied unchanged from Debian Trixie mingw-w64-common 12.0.0-5.
GCC-MinGW-14.2.0-COPYRIGHT.txt: copied unchanged from Debian Trixie gcc-mingw-w64-base 14.2.0-19+27+b1; includes the GCC Runtime Library Exception. The upstream Debian notice includes historical packaging descriptions; no claim is made that the current compiler is GCC 9.

Official distribution origins: https://static.rust-lang.org/dist/2026-10-15/ and https://deb.debian.org/debian/ . Exact package URLs and SHA256 values are recorded in the build verification artifact.
